# 小说改竖屏短剧 · 改编指南

## 改编流程（推荐）

1. **读源**：确定改编章节范围、题材、目标集数（通常 60–100 集）
2. **抽骨架**：主线冲突、主角欲望、反派阻力、3–5 个关键情节点
3. **分集地图**：每集 1 个「集内目标 + 集末钩子」，每 10 集一个阶段高潮
4. **写场次**：按 script-format 模板产出，先粗后细
5. **验节奏**：用 evaluate_script 跑指标，再人工修钩子

## 分集地图模板

```yaml
episode: 1
title: "婚礼上的羞辱"
source_chapters: "小说第1-2章"

  - "反派首次亮相，立下对立"
hook: "女主收到神秘短信：你的真实身份已被查到了"
paywall_candidate: false
```

## 题材节奏参考

| 题材 | 开集策略 | 钩子类型 |
|------|----------|----------|
| 甜宠 | 3 场内建立 CP 张力 | 误会/吃醋/壁咚 |
| 虐恋 | 第 1 集即核心伤害 | 背叛/错过/身份错认 |
| 复仇 | 第 1 集展示受辱/失去 | 觉醒/归来/第一次反击 |
| 悬疑 | 第 1 集抛核心谜题 | 新线索/反转/危险逼近 |
| 玄幻/穿书 | 快速交代规则 | 系统提示/死亡 flag/金手指 |

## 从网文到短剧的常见映射

| 网文元素 | 短剧处理 |
|----------|----------|
| 内心独白 500 字 | 1 句 OS 或拆成 2–3 轮对白 |
| 修炼/升级描写 | 视觉符号（光效、数值字幕、他人反应） |
| 长篇回忆 | 30 秒闪回 + 1 句点题对白 |
| 多线叙事 | 主视角优先，副线用电话/消息/同框带过 |
| 章末悬念 | **必须保留并加强**为集末钩子 |

## 付费卡点设计（若做商业化）

- 第 8–12 集附近设第一个强卡点
- 卡点 = 身份即将揭露 / 真相一半 / 情感临界点 / 生死未卜
- 卡点前 1 集结尾就要开始「抬情绪」，卡点集给最大信息增量

## 改编自检清单

- [ ] 删掉所有「他想起」「她意识到」类叙述，是否还能看懂？
- [ ] 新观众只看本集，能否理解谁要什么、怕什么？
- [ ] 每 30 秒是否有一个小推进（信息/情绪/关系变化）？
- [ ] 集末是否让人想点下一集？
- [ ] 台词念出来是否顺口、像人话？
