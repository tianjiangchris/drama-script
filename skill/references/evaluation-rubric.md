# 竖屏短剧剧本评估量表

## 总分结构（100 分）

| 维度 | 权重 | 考察点 |
|------|------|--------|
| 节奏与钩子 | 25 | 开场抓力、场间推进、集末悬念 |
| 对白质量 | 25 | 口语化、信息量、人设区分度 |
| 可视化 | 20 | 动作可拍、竖屏镜头感、少旁白 |
| 结构规范 | 15 | 场次完整、格式统一、字数达标 |
| 改编契合 | 15 | 保留核心冲突、无跑题、人设一致 |

## 评级

| 分数 | 等级 | 说明 |
|------|------|------|
| 85–100 | A 可拍摄 | 小修即可进入拍摄/分镜 |
| 70–84 | B 可用 | 结构 OK，需改对白或钩子 |
| 55–69 | C 待改 | 节奏或可视化问题明显 |
| <55 | D 重写 | 不符合短剧形态 |

## 节奏与钩子（25 分）

- **开场（8）**：前 2 场是否进入冲突或悬念？纯铺垫 > 1 场扣 3 分
- **场间推进（9）**：每场是否有信息/情绪/关系变化？空转场扣 2 分/场
- **集末钩子（8）**：最后 1–2 场是否有明确悬念/反转/强情绪？无钩子最多 3 分

## 对白质量（25 分）

- **口语化（8）**：书面语、说明性对白过多扣分
- **信息量（9）**：废话、重复解释扣分；有效推进加分
- **人设（8）**：主要角色对白能否区分？全员同一语气扣 3–5 分

## 可视化（20 分）

- **可拍性（10）**：抽象描写、不可视心理过多扣分
- **竖屏意识（5）**：特写、表情、道具、字幕提示
- **旁白控制（5）**：旁白/叙述超 20% 扣分

## 结构规范（15 分）

- 场次标号、时间地点人物齐全（5）
- 单集字数 400–900（5）
- 格式符号统一（△、括号）（5）

## 改编契合（15 分）

- 与 adaptation_brief 目标一致（8）
- 未丢失核心冲突/误删关键埋线（7）

## 常见问题 → 修改建议

| 问题 | 建议 |
|------|------|
| 集末无钩子 | 加一句未答问题、反常动作、或新信息入场 |
| 对白像念小说 | 拆短句，加打断、反问、潜台词 |
| 场戏拖 | 合并场景，删过渡，用道具/电话一笔带过 |
| 人物扁平 | 给每个主要角色 1 个语言习惯（口头禅/语速/用词） |
| 竖屏感弱 | 增加特写动作行：「△ 特写：手指收紧」 |
