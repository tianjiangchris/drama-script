# 竖屏短剧剧本格式规范

## 基本结构

每集剧本包含：
- **集标题**：第 N 集 · 副标题（可选，用于概括本集钩子）
- **场次**：按 1、2、3… 编号
- **每场必填**：时间、地点、出场人物
- **正文**：△ 动作/镜头描述；角色名+台词

## 场次模板

```
第 3 集 · 真相逼近

【场次 1】
时间：日
地点：公司茶水间
人物：林晚、陈总

△ 林晚倒咖啡，手机震动，屏幕特写：匿名消息「你老公昨晚在哪？」

林晚：（压低声音）谁？

△ 陈总从背后走近，林晚迅速锁屏。

陈总：林总，季度报表还没交？

林晚：（强笑）马上。

【场次 2】
...
```

## 竖屏短剧硬性指标

| 指标 | 建议范围 | 说明 |
|------|----------|------|
| 单集字数 | 400–900 字 | 对应 1–2 分钟竖屏 |
| 场次数 | 2–5 场 | 场太多节奏碎，太少信息不足 |
| 单场时长感 | 15–40 秒 | 每场至少一个信息点或情绪转折 |
| 台词占比 | ≥ 55% | 短剧靠对白推进，减少旁白 |
| 单句台词 | ≤ 25 字 | 竖屏字幕可读性 |
| 集末钩子 | 必须有 | 悬念/反转/情绪爆点/新信息 |

## 符号约定

- `△`：动作、表情、镜头（竖屏可写「特写」「切至」）
- `（）`：括号内为语气/潜台词/OS 内心独白
- `【闪回】` / `【字幕】`：特殊段落，单场最多 1 次
- 禁止大段文学性旁白；必要信息拆进对白或动作

## 改编时的删减原则

1. **保留**：核心冲突、人设标签、每 3 集一个大反转、付费卡点前的强钩子
2. **合并**：功能重复的路人、可一句带过的过渡场景
3. **外化**：心理活动 → 对白/动作/道具（如攥紧的离婚协议书）
4. **前置**：网文慢热铺垫 → 第 1 集前 30 秒必须出现主冲突或强悬念
